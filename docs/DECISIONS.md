# Decision Log

## 2026-08-14 — Project initialized

- Actual target cycle recorded as ICLR 2027; repository slug retained.
- Main unit of explanation fixed to editable input-text spans.
- LOCA recognized as the closest conceptual prior work; broad “first local causal jailbreak explanation” claims prohibited.
- Attention-head discovery removed from the main contribution list.
- Wavelet/tree-Haar component marked provisional and subject to an explicit algorithm gate.
- Phase 1 prioritizes phenomenon viability over full implementation.
- Frozen evaluation sets, matched controls, confidence intervals, compute logs, and diff inspection are mandatory.

## 2026-08-24 — Token-level causal-structure extension recorded and locked

- The SHIPs/SAHARA component-ablation and greedy-set-search motif may be used as a conceptual prior and baseline, not as the novelty claim.
- Token-level work is authorized only as a refinement inside a previously recovered wrapper node or sentence region after evaluator qualification and the parent oracle pass.
- Primary evidence is seed-stable full-response harmful-assistance reduction plus refusal/safe-redirection recovery; KL or next-token divergence is secondary diagnostic evidence only.
- The paper-facing object is a robust recovery token set validated across at least two independent text-level interventions, with payload invariance and capability-confound rejection.
- Inclusion-minimality and minimum-cost optimality are distinct; strict subsets and all tied/incomparable sets must be retained.
- Greedy SAHARA-style search is a baseline and cannot establish minimality or pure token interaction.
- Cases must be separated into atomic, sparse additive, sparse synergistic, distributed-under-cap, confounded, abstained, invalid, and budget-unresolved outcomes.
- Public attack compression and raw minimal-token release are prohibited by default; recovery equivalence to the parent span is the preferred defensive analysis.
- No Stage A, evaluation-30, held-out, exact-oracle, or wavelet boundary is opened by this decision.
