# E0 h4rm3l Real-Template Payload-Invariance Audit v1

Date: 2026-08-24 (Asia/Seoul)

## Purpose

The first h4rm3l admission audit verified safe parameterized wrappers. The second verified typed unit manifests and two subset neutralizers on harmless synthetic compositions. This third audit applies the same pre-outcome machinery to h4rm3l's actual default semantic jailbreak templates while still using only a harmless sentinel payload and no target model.

This is the final h4rm3l Regime-S adapter admission test before target-model screening can be considered under a later balanced contract.

## Frozen programs

Seven predeclared programs cover representative semantic strategies:

1. AIM persona + refusal suppression + affirmative prefix;
2. cipher framing + affirmative prefix;
3. few-shot harmful-demonstration framing + affirmative prefix;
4. research framing + villain persona;
5. DAN persona template;
6. STAN persona template;
7. distractor template.

They contain twelve typed components. Their nineteen non-empty component subsets are each tested under deletion and layout-preserving blanking, yielding thirty-eight neutralized variants.

## Admission questions

The audit asks only whether:

- each actual template embeds its complete input exactly once;
- the fixed sentinel remains one contiguous, byte-identical occurrence;
- `.then()` composition yields a complete typed fragment partition;
- full-chain compilation matches sequential component application;
- every component subset can be neutralized by both frozen operators;
- no template invokes a synthesis model;
- no target model or attack-success evaluator is called;
- no raw template or rendered prompt crosses the safe boundary.

## Why this is not an attack experiment

The sentinel is harmless and the target model is never invoked. Passing this audit does not establish that any template jailbreaks any model, nor that any component is behaviorally causal. It establishes only that h4rm3l has a reproducible, payload-preserving, pre-outcome adapter suitable for later balanced screening.

## Pass rule

A pass requires:

- seven of seven programs pass;
- twelve components and nineteen subsets exactly match the frozen budget;
- all thirty-eight neutralized variants preserve the sentinel and satisfy length rules;
- fragment partitions and sequential/full-chain equivalence pass;
- model prompting and target-model calls remain zero;
- all scientific boundaries remain sealed.

A pass freezes h4rm3l as one eligible Regime-S attack-family adapter. It does not open Stage A. The overall S/F/U matrix still requires the second S family and both F/U families to pass their own E0 audits, plus independent evaluator-panel qualification.
