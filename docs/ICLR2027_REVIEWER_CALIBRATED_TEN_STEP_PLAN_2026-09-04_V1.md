## Mandatory progress-report format

Every interim and completion report must state, in this order:

1. completed step number and result status;
2. current or next step number and its concrete operation;
3. estimated remaining wall-clock time as a range, with the basis for the estimate;
4. whether the run is normal, delayed, failed, or waiting for a resource;
5. what scientific meaning is earned if the current step passes, and what is still not established.

Before a run has supplied a measured throughput, label the estimate provisional. Once throughput is
available, replace it with a measured ETA and revise it whenever the observed rate or workload
changes materially. Never present an unsupported point estimate.
